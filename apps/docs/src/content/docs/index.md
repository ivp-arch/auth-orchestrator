> **Pre-alpha.** This documentation grows together with the library: a page is added when the
> feature it describes is implemented.

Auth Orchestrator handles Authorization Code + PKCE, token storage and refresh, multi-tab sync,
route guards and HTTP interceptors for Angular and React SPAs, with any standards-compliant
OpenID Connect provider.

- Angular: [`@auth-orchestrator/angular`](https://www.npmjs.com/package/@auth-orchestrator/angular)
- React: [`@auth-orchestrator/react`](https://www.npmjs.com/package/@auth-orchestrator/react)
- Core: [`@auth-orchestrator/core`](https://www.npmjs.com/package/@auth-orchestrator/core)
