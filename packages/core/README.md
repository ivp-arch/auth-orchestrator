# @auth-orchestrator/core

Framework-agnostic OAuth 2.0 / OIDC orchestrator for SPAs.

> ⚠️ **Alpha**: API is not stable. Do not use in production yet.

## Installation

```bash
pnpm add @auth-orchestrator/core
```

## Usage

This package is the framework-agnostic core. You probably want one of:

- [`@auth-orchestrator/react`](../react) for React applications
- [`@auth-orchestrator/angular`](../angular) for Angular applications
